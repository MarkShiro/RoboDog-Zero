# RoboDog Zero: документация Orange Pi и Mega

Для повторения полной сборки начните с [порядка пусконаладки](../commissioning.md). Он ведёт от проверки питания и пульта к карте концевиков, калибровке Mega, вертикальному дисплею Orange Pi и первому HOME. Если датчики подключены не по предполагаемым номерам J, используйте [отдельную инструкцию](../limit-switches.md): в ней есть проверка каждого контакта NO/NC и переназначение входов D42–D49.

| Документ | Назначение |
|---|---|
| [Инструкция Orange Pi](../../orange_pi/README.md) | openEuler 22.03 на AIpro 8T, Bluetooth, Mega, SPI TFT 240×320, касание, Coin D6 USB–UART |
| [Инструкция Mega](../../firmware/RoboDogMegaFinal/README.md) | Электрическая таблица, ток TMC2209, состояния, поиск нулей и походка |
| [Локальный профиль калибровки](../../commissioning/README.md) | Создание и проверка `calibration.h` из измерений собственного экземпляра |
| [Бланк измерений](Mega-calibration-worksheet.csv) | Запись J1–J8 в ходе стендовых проверок |
| [Подробный план первого включения](OrangePi-AIpro-8T-openEuler-RoboDog-plan.md) | Расширенная инвентаризация ОС и аппаратных интерфейсов |

`orange_pi_inventory.sh` читает состояние самой платы и не изменяет конфигурацию. Его вывод может содержать адреса сети и имена устройств, поэтому просматривайте файл перед публикацией. [Исторический журнал настройки](../Bringup-2026-09-25.md) сохранён для исходных расчётов; при расхождении с текущим кодом используйте документы выше.
