# RoboDog Zero: прошивки и запуск

Комплект исходного кода для квадропеда с **Arduino Pro Mini 3,3 В/8 МГц**, **Arduino Mega 2560**, **Orange Pi AIpro 8T** на образе `opiaipro_openEuler22.03_desktop_aarch64_20240604`, восемью TMC2209 и двигателями 1,8°/1,5 А на фазу. Редуктор **12:1**; батарея **8S LiFePO4**. Для итоговой механики принимаются восемь концевиков. Две платы по четыре драйвера обслуживают левую и правую стороны; какая электрическая J-группа соответствует конкретной стороне, определяется измерением.

Рабочая цепочка: пульт → HC-05 Bluetooth Classic → Orange Pi → `Serial3` Mega → две UART-шины TMC2209 и STEP/DIR. Обратно Mega передаёт телеметрию на пульт и IMU на сенсорный экран. COIN-D6 подключён к Orange Pi **через комплектный переходник USB–UART**. На экране 2,4″ 240×320 три вкладки внизу: анимированное лицо, IMU, LiDAR.

Комплект сопровождает реальную поэтапную сборку. **Готовый исходный код не означает уже откалиброванного робота.** Карта восьми моторов, знаки, положение концевиков, диапазоны суставов, Rsense, цепь аварийной кнопки и часть интерфейсов Orange Pi ещё требуют проверки на физическом экземпляре. Mega `ROBOT_CALIBRATED=false` и не разрешает моторы по умолчанию; экспериментальная рысь выключена отдельно. Не заменяйте эти проверки выдуманными значениями. Временный режим нуля в позиции при включении доступен для стенда и документирован в инструкции Mega; основной режим полного комплекта ищет ноль по концевикам.

Первый практический проход: проверить отдельный пульт → собрать и загрузить `RoboDogMotorMap` → записать, какой J двигает какую ногу и в каком направлении → проверить каждый концевик/аварийную цепь/питание → заполнить `calibration.h` → загрузить основную Mega с заблокированной ходьбой → настроить Orange Pi и интерфейсы → испытать стойку на опоре → лишь затем включать опытную походку в ограниченном диапазоне. Указанные владельцем 30–40° относятся к положению ног относительно горизонта; их нельзя автоматически записать как электрические пределы каждого из восьми валов.

## Что реально готово и что зависит от железа

- Прошивки Pro Mini и обе прошивки Mega скомпилированы для указанных плат; есть host-тесты протокола, блокировки, движения и относительного нуля.
- Orange Pi рендерит все три страницы в PNG и предоставляет SPI/XPT2046 backend, Bluetooth-мост, интерфейс Mega, прямой декодер формата COIN-D6/CSPC TOF и сбор сырых байтов для диагностики. Демо-данные всегда подписаны.
- Драйвер конкретного TFT (ST7789/ILI9341), GPIO offsets и калибровка касания определяются на плате. Фото модуля подтверждает **2,4″**, но маркировка контроллера по нему недостаточна.
- Прямой декодер COIN-D6 написан по открытому ROS SDK и прошёл синтетический пакетный тест. Формат не подтверждён байтами **конкретного датчика** владельца: реальный скан и его ориентацию ещё нужно проверить на месте. Есть JSON-lines интерфейс внешнего SDK. Программа не выдаёт тестовую картинку за реальные показания.
- Автономная ходьба и корректное выключение питания Orange Pi по запросу Mega остаются этапами физической интеграции. Сейчас Pi не использует NPU или камеру для управления.

Исходные схемы, архивы переписки и сторонний установщик драйвера не публикуются в репозитории: здесь размещены собственные исходники и инструкции. При обращении к старым материалам отличайте исторические описания от измеренного состояния робота.
