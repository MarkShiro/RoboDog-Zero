# Локальный профиль робота

Из корня репозитория создайте `robot.json` командой `python tools/generate_calibration.py --init commissioning/robot.json`. Файл исключён из Git, поскольку номера проводов, углы и результаты проверки относятся к одному физическому экземпляру. Заполняйте его по [порядку пусконаладки](../docs/commissioning.md) и [проверке концевиков](../docs/limit-switches.md).

Генератор откажется создавать прошивку, пока нет восьми уникальных осей, восьми уникальных входов D42–D49, знаков, углов и пределов поиска. Первый запуск без `--unlock` оставляет ARM заблокированным для проверки логической карты концевиков через `STATUS`. `--unlock` разрешён лишь после отметки всех физических проверок в `verified`; `--enable-trot` требует `--unlock` и отдельного испытания походки. Эти флаги фиксируют действия оператора, а не выполняют измерения сами.

Числа углов в JSON задаются в **градусах** (например, `35.25`), генератор переводит их в сотые градуса для Mega. `trot_amplitude_deg` — амплитуда суставной команды, а не положение ноги относительно горизонта. Редуктор 12:1 и 1/16 микрошагов должны совпадать с компилируемой прошивкой.
